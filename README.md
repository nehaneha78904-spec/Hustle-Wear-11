# 🛍️ HUSTLE WEAR — Elevated Indian Streetwear

A full-stack e-commerce platform built with React (Vite) + Node.js/Express + MongoDB.

## Stack
- **Frontend**: React + TypeScript + Vite + Tailwind CSS v3 + Zustand + Framer Motion
- **Backend**: Node.js + Express.js + MongoDB (Mongoose) + JWT Auth
- **Frontend Hosting**: Cloudflare Pages
- **Backend Hosting**: Render
- **Database**: MongoDB Atlas

## Quick Start
See [DEPLOYMENT_GUIDE.md](./DEPLOYMENT_GUIDE.md) for full setup instructions.

```bash
# Backend
cd hustle-wear-backend && npm install && npm run dev

# Frontend  
cd hustle-wear-frontend && npm install && npm run dev
```

## Features
- 🏠 Editorial homepage with animated marquee, hero section, category grid, trending products
- 🛍️ Product catalog with advanced filtering (category, dept, size, price, GSM, sort)
- 📦 Product detail page with image gallery, size/color selector, reviews
- 🛒 Cart drawer with real-time updates
- ❤️ Wishlist functionality
- 💳 Multi-step checkout (Address → Delivery → Payment → Review)
- ✅ Order confirmation with tracking
- 🔐 JWT authentication (register/login)
- 📱 Fully responsive design
